Use this map to connect concepts to responsibilities. Each chapter supplies a synthetic example and a practical exercise rather than a private source-code snapshot.

RAG and engineering foundations

  • RAG foundations — Build the mental model before choosing infrastructure.
  • Architecture and design patterns — Understand the dependency boundaries and why each seam exists.
  • Sources, connectors, and extraction — Reliable knowledge starts with knowing what was actually scanned.
  • Chunking and document structure — Treat chunking as an information boundary, not a magic constant.
  • Embeddings and resilient execution — Protect vector compatibility, provider capacity, and tenant data.
  • Vector storage and database design — Choose guarantees as carefully as similarity algorithms.
  • Retrieval, fusion, and reranking — Find candidates, enforce constraints, then spend ranking effort wisely.
  • Evidence, context, and citations — Turn ranked hits into bounded material a person can verify.
  • Ingestion and transaction ownership — Keep expensive preparation outside the critical mutation window.
  • Distributed sync, jobs, and recovery — Reason about stale workers and partial writes using explicit state.
  • Security, tools, and trust boundaries — Connect identities to scopes before exposing knowledge to users or agents.
  • Evaluation, testing, and operations — Turn service requests about quality and reliability into repeatable evidence.
  • Deep learning and generative AI — Learn the model concepts behind the interfaces without confusing them with implemented features.
  • From subsystem to AI full-stack product — Build the application around the evidence contract and demonstrate engineering judgment.

Application, data, and identity

  • A reference AI application end to end — Connect the reusable RAG library to the concrete the support platform backend.
  • Relational data modeling and migrations — Learn why the application needs more than a vector index.
  • Transactions, locks, and concurrency — Prove what happens when retries, users, and workers race.
  • Securing database operations — Constrain credentials, queries, disclosure, and recovery—not only SQL strings.
  • API identity and application security — Carry trusted user identity through routes, tools, workers, and streams.
  • ADK agents, tools, and memory — Understand the implemented runtime before comparing alternatives.

Frameworks, evaluation, and delivery

  • LangChain as an integration alternative — Learn the abstractions while keeping business authority in existing services.
  • LangGraph stateful workflows — Design an explicit workflow without confusing checkpoints with business commits.
  • A2A and distributed agent collaboration — Treat remote agents as services with identity, tasks, and failure—not shared thoughts.
  • Evaluating agents and application outcomes — Measure the trajectory and durable effects, not just a fluent answer.
  • Agent and RAG evaluation libraries — Choose tools by measurement need, data access, and reproducibility.
  • Agent observability and trace privacy — Connect requests, tool outcomes, model spend, and business results.
  • Evidence applicability and decision boundaries — Separate support explanations, contractual applicability, and authoritative decisions.
  • Full-stack streaming and user workflows — Carry backend truth into browser state, confirmation, and feedback.
  • Deployment, recovery, and production readiness — Turn local mechanisms into a measured deployment contract.
  • Model engineering and the advanced learning path — Connect representation, uncertainty, serving, and experimentation to actual failures.

Context and prompt engineering

  • Context engineering — Build the information environment that makes the next model action reliable.
  • Context optimization and memory budgets — Measure, select, compress, and cache context without losing critical evidence.
  • Prompt engineering foundations — Specify tasks, evidence, output contracts, and uncertainty clearly.
  • Prompt techniques and structured reasoning — Choose decompositions and verification methods by measured task need.

MCP, skills, orchestration, and harnesses

  • MCP foundations and capability contracts — Connect agents to tools, resources, and prompts through explicit boundaries.
  • Build and secure an MCP server — Engineer an adapter with scoped tools, observable outcomes, and deployable contracts.
  • Skills and layered agent capabilities — Package reusable expertise while preserving policy, permissions, and context efficiency.
  • Agent orchestration and durable workflows — Coordinate steps, parallel work, state, approvals, and recovery.
  • Agent design patterns and trade-offs — Use patterns to solve concrete coordination and reasoning problems.
  • Agent harnesses, runtime control, and secure execution — Build the environment that runs, limits, observes, and recovers an agent.

Evaluation, streaming, and multimodal products

  • Evaluation engineering and release decisions — Prove that agents complete useful work and recover safely.
  • Backend integration with agents — Connect identity, business services, durable operations, and model runtimes.
  • SSE and resilient HTTP streaming — Deliver ordered server events with framing, reconnection, and honest completion.
  • WebSockets and bidirectional systems — Engineer duplex sessions with identity, flow control, and reconnection.
  • Voice agents and realtime audio — Build conversational audio with turn control, interruption, and safe actions.
  • OCR and document intelligence — Turn images and documents into grounded, reviewable information.
  • Live agents, event-driven work, and realtime state — Keep long-lived assistants responsive, bounded, and recoverable.
  • Build, evaluate, and publish your AI engineering portfolio — Turn the roadmap into working systems and evidence of engineering judgment.
