1"""Procedures domain adapter: playbook ingestion, retrieval, and the tool.
2
3The procedures index is a second document index next to the policy one. It holds
4domain procedure playbooks — the coverage determination checklist and the intake
5triage procedure — so compliance can change a procedure by editing a markdown
6file in ``app/data/procedures/`` instead of editing the system prompt.
7
8"Skills" in this package means DOMAIN PROCEDURE PLAYBOOKS retrieved as documents
9through that second index. Two other readings were rejected, and the reasoning is
10recorded here so it is not re-litigated:
11
12- Claude-style on-disk skill bundles (``SKILL.md`` plus scripts) have no loader
13  in ADK 1.3, so there is nothing to register them with.
14- The OpenAI Skills API is not consumable here: the app drives models through
15  ``LiteLlm`` on ADK's chat-completions path rather than the Responses API, so a
16  ``skill_reference`` cannot be attached to a request.
17
18The chosen reading also matters for cost. The system prompt is already dense and
19every added rule is paid for on every turn, so the playbook bodies stay out of
20the prompt and are loaded on demand by ``get_procedure``.
21"""
