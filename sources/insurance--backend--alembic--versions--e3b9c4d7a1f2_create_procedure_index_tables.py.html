7Creates the procedures index: the ``procedure_chunks`` table the playbooks are
8retrieved from, and the ``procedure_versions`` table their ingestion snapshots
9live in. It is a second index, not an extension of the policy one, so a policy
10re-ingest can never retire a procedure version.
11
12The tsvector trigger is not optional: the hybrid retriever's keyword stage is a
13plain ``tsvector @@ plainto_tsquery`` predicate, and without it the full-text
14half of every procedure search would silently return nothing.
15"""
