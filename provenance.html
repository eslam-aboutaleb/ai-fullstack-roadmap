HOW TO READ THIS HANDBOOK

Evidence before certainty.

Snapshot and inputs

Package and example excerpts are read directly from Git commit e57f6468d334190d519df375e5feeb6149031da2. The supplied Markdown guide and .archify artifacts were untracked workspace inputs. Their content is treated as reference material, not as proof of current runtime behavior.

The existing working tree also contained changes to docs/vector-stores.md and sonar-project.properties and an untracked src/ragit directory. This handbook leaves them untouched and uses committed src/ragnor code for source claims.

Source hashes and copied-diagram hashes are recorded in manifest.json. Rebuild with python3 docs/learning-guide/build.py from the repository root.

Corrections and boundaries carried into the answers

  • No universal transaction-time benchmark is claimed; the critical section includes actual writes.
  • The generic hybrid strategy awaits dense then lexical stages sequentially.
  • Sliding-window chunk sizes are words; physical chunk IDs are UUIDs.
  • Fallback token overlap is not BM25 or equivalent to native PostgreSQL full-text ranking.
  • Shared-session atomicity depends on participating adapters; remote stores do not join a SQL transaction automatically.
  • Production distributed fencing requires durable atomic adapters; in-memory coordination is process-local.
  • Remote transport security has permissive integration defaults that hosts must configure.
  • The executor has a semaphore; its bounded-queue docstring is not evidence of a separate configurable queue bound.
  • Approximate token counts do not guarantee a real model context limit.
  • Training, GraphRAG, multimodal retrieval, the chat UI, and the production application are proposed learning extensions where labeled.

Portability and privacy

The handbook needs no build dependencies or network requests for its core reading, search, progress, or copied diagrams. GitHub and paper links are optional external references. Existing diagram viewer exports retain their original runtime behavior.

For consistent browser-local storage, serve this folder: python3 -m http.server 8765 --directory docs/learning-guide, then visit http://localhost:8765. Opening index.html directly also supports reading and search. Keep the whole folder together when sharing it.

Notes and progress are saved locally when browser storage is available. Export a backup before clearing browser data. They are not synchronized to a server.
