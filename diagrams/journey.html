What proves progress?

  1. Run an offline search and explain its fake embedding.
  2. Compare retrieval settings on held-out labeled questions.
  3. Reject cross-scope source lookup and stale-worker activation.
  4. Build a host API and citation UI with explicit failure states.
  5. Demonstrate retries, revision lookup, rollback, and recovery.

What is outside the library?

The host supplies authentication, durable production adapters, chat generation, deployment, and user experience.

Training methods such as LoRA and DPO are learning extensions. They are not implemented by this retrieval subsystem.
