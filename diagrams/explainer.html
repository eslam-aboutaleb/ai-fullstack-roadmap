How does Ragnor provide a domain-agnostic RAG subsystem?

Long image

A

Answer

Ragnor decouples chunking, embedding, vector storage, and hybrid retrieval from application models through protocol seams.1

  1. Host applications inject database sessions, settings, and tables without modifying Ragnor code.2
  2. Two-phase ingestion prevents slow remote embedding calls from holding database locks.
  3. Hybrid retrieval merges dense vector distance and sparse full-text search using Reciprocal Rank Fusion.
  4. EvidenceAssembler bounds context tokens deterministically for reliable LLM prompting.3

How does the hybrid retrieval pipeline work?

Diagram structure
  • Host Application app
  • HybridRetriever retriever
  • VectorStore store
  • EvidenceAssembler assembler
  • app → retriever · search(query, k=5)
  • retriever → store · hybrid_search(vector, text)
  • store → retriever · hits (ANN + BM25)
  • retriever → assembler · assemble(hits, budget)
  • assembler → retriever · EvidenceBundle
  • retriever → app · bounded context
  1. Query Embedding ↗

    Converts search text into a vector using the registered embedding function.

  2. Hybrid Store Query ↗

    Runs vector similarity search and full-text keyword search in parallel.

  3. Reciprocal Rank Fusion ↗

    Fuses dense and sparse rankings to produce robust search hits.

  4. Evidence Assembly ↗

    Deduplicates, merges contiguous text spans, and enforces ContextBudget.
