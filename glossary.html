REFERENCE / 144 TERMS

Decode the vocabulary.

Definitions with practical boundaries. Expand the relevant chapter for mechanisms and risks.

AI — Artificial Intelligence

The broad field of systems performing intelligent tasks. In this project, deterministic backend engineering surrounds learned-model calls.

ML — Machine Learning

Learning behavior from examples rather than specifying every rule. Embedding providers use learned representations; most orchestration here is ordinary software.

DL — Deep Learning

Machine learning with layered neural networks. Learn vectors, training objectives, attention, and inference alongside the backend.

NLP — Natural Language Processing

Computational work with language, including retrieval, embedding, classification, and generation.

GenAI — Generative AI

Models producing new outputs. A generated answer is not automatically verified by its fluency.

LLM — Large Language Model

A large trained language model. The host supplies the ordinary answer generator; the library focuses on retrieval infrastructure.

RAG — Retrieval-Augmented Generation

Retrieval supplies external evidence to a generation process. Index freshness and answer faithfulness remain separate obligations.

Embedding

A numerical representation of input used for comparison. Dimension alone does not identify its vector space.

Vector dimension

The number of coordinates. Validate it before indexing and keep model/profile identity alongside it.

Cosine similarity

Direction similarity, equal to dot product for unit vectors. It is not a probability that a passage is correct.

L2 — Euclidean distance

Straight-line distance between vectors. Lower values indicate geometric closeness under this metric.

Dot product

The sum of coordinate-wise products. Without normalization, vector magnitude influences ranking.

Bi-encoder

Encodes queries and documents separately so document vectors can be precomputed.

Cross-encoder

Processes a query-document pair jointly for scoring; often used after candidate retrieval because it costs more per pair.

ANN — Approximate Nearest Neighbor

Faster vector search that may miss exact nearest neighbors. Actual behavior depends on backend index configuration.

HNSW — Hierarchical Navigable Small World

A graph-based ANN index family. Memory, search effort, and recall require backend-specific tuning.

IVF — Inverted File index

An ANN approach partitioning vectors into regions. It is a backend indexing concept, not a universally enabled Ragnor feature.

FTS — Full-Text Search

Token-based search infrastructure. PostgreSQL native FTS differs from the shared token-overlap fallback.

BM25

A term-frequency and inverse-document-frequency ranking family with length normalization. The fallback overlap helper is not BM25.

RRF — Reciprocal Rank Fusion

Merges ranked lists by reciprocal rank contributions; the helper uses one-based ranks and k=60.

candidate_k

The candidate pool for later ranking. A reranker cannot recover a passage absent from this pool.

final_k

The final result limit after ranking and validation. Distinct from the evidence token budget.

Reranker

An additional scorer that reorders candidates. Its provider latency and data-disclosure policy matter.

Query expansion

Generating or deriving alternate search formulations. Bound variant count, length, runtime, and scope.

HyDE — Hypothetical Document Embeddings

Retrieving with a generated hypothetical document representation. A proposed extension, not a default implemented method here.

GraphRAG

Retrieval or synthesis that uses graph relationships. Requires additional graph and controller design beyond a connector.

Agentic RAG

A controller chooses repeated retrieval or tool actions. Needs explicit iteration, permission, time, and cost limits.

Token

A model-specific text unit. Words, characters, and tokens are different measures.

Context window

The input/output token capacity of a model interaction. Exact accounting must include the actual serialized request.

Grounding

Connecting claims to supplied evidence. It enables verification but does not automatically prove truth.

Hallucination

Generated content unsupported by the relevant evidence or facts, despite potentially fluent wording.

Faithfulness

Whether an answer follows its provided evidence. An answer can be faithful to an obsolete source.

Provenance

Source identity, revision, location, and transformation history needed to trace evidence.

Chunk

A retrieval subdivision of a document. Its size and boundaries influence both relevance and context integrity.

Overlap

Repeated content between chunks. Improves some boundary coverage while increasing embedding work and redundancy.

Snapshot

A recorded source or indexing state. Ingestion snapshots identify processing compatibility; source snapshots support revision lookup.

Fingerprint

A stable representation or hash of meaningful configuration and input identity. It must exclude secrets and include behavior-changing fields.

SHA-256

A cryptographic hash producing 256 bits, commonly represented as 64 hexadecimal characters. Hash equality is not authorization.

TTL — Time To Live

An expiry duration used for caches or leases. Expiry is not a replacement for explicit revocation.

LRU — Least Recently Used

An eviction policy removing older unused cache entries when capacity is exceeded.

Idempotency

Repeating an operation reaches the same intended logical state. It does not promise one physical execution or one provider charge.

CAS — Compare-And-Swap

Update state only if the expected current version matches. Batch CAS must be atomic when whole-batch visibility is promised.

Fencing token

A monotonic epoch used to reject obsolete workers at authoritative writes.

Lease

Time-bounded ownership. A worker may resume after expiry, which is why fencing is also needed.

Tombstone

Logical deletion metadata that hides content before asynchronous physical cleanup finishes.

Generation

An indexed revision cohort used to decide which vectors are currently visible.

Outbox

A durable work record committed with the business change it represents, then processed asynchronously.

SKIP LOCKED

A SQL claiming mechanism that avoids rows locked by another worker. It does not provide exactly-once execution.

At-least-once processing

Work may repeat after failures. Processors need safe logical deduplication or idempotent effects.

Backpressure

Slowing or rejecting producers when consumers cannot keep up. A semaphore only bounds its own in-flight operations.

Semaphore

A concurrency primitive limiting simultaneous entrants. Per-instance limits do not combine into a fleet-wide quota.

Jitter

Random variation in retry delay to reduce synchronized retry bursts.

ORM — Object-Relational Mapper

Maps programming objects to relational data. Raw SQL may still be appropriate for backend-specific retrieval queries.

CTE — Common Table Expression

A named SQL query expression useful for composing retrieval stages. Query plans still determine execution behavior.

ACID

Atomicity, Consistency, Isolation, Durability: transaction properties whose actual scope depends on participating storage systems.

DI — Dependency Injection

Supplying collaborators from outside a component. Ragnor uses this for settings, sessions, stores, and models.

Protocol

A Python structural interface. Matching methods does not prove transactional or security semantics.

Hexagonal architecture

Ports describe core needs and adapters connect infrastructure. The host retains domain and deployment ownership.

Strategy pattern

Interchangeable behavior behind a contract, such as dense, lexical, or hybrid retrieval.

Factory pattern

Centralizes construction of collaborators. It does not by itself choose safe production defaults.

Builder pattern

Stepwise readable assembly of a configured object. Local convenience defaults need explicit production review.

Facade pattern

A consolidated interface over subsystems; KnowledgeBridge provides such an integration boundary.

Null Object pattern

A no-op implementation such as NullEventSink that avoids repeated optional checks.

MCP — Model Context Protocol

A tool/resource integration protocol. Transport identity and server authorization remain necessary.

SSRF — Server-Side Request Forgery

Untrusted URLs cause a server to reach unintended destinations. Validate DNS, redirects, and actual connection targets.

XSS — Cross-Site Scripting

Untrusted content executes in a browser. Render document text safely rather than as arbitrary HTML.

CORS — Cross-Origin Resource Sharing

Browser origin policy controls. It does not authenticate callers or protect against all non-browser access.

RBAC — Role-Based Access Control

Permissions derived from roles. A host can map readers, operators, and administrators to tool permissions.

ABAC — Attribute-Based Access Control

Authorization using attributes of identity, data, and context. Scope filters are only one part of enforcement.

Prompt injection

Untrusted content attempts to control the model or its tools. Escaping selected tags is only a limited mitigation.

PII — Personally Identifiable Information

Data identifying a person. Consider it in source text, queries, metadata, snapshots, and logs.

OTel — OpenTelemetry

Observability APIs and conventions. The optional bridge connects events to host-managed instrumentation.

SLO — Service Level Objective

A measurable reliability target. Establish it from real workloads rather than illustrative diagram timings.

p95 / p99

Latency percentiles describing tail behavior. An average does not reveal overload or retry tails.

Recall@K

Fraction of labeled relevant items retrieved within K positions. Labels and chunk identity must remain compatible.

Precision@K

Fraction of the evaluated top-K positions that are relevant; inspect denominator conventions across tools.

MRR — Mean Reciprocal Rank

Average reciprocal position of the first relevant hit, with zero for no hit.

NDCG — Normalized Discounted Cumulative Gain

A ranking metric supporting graded relevance and rank discounting. Broader theory, not a claimed default harness metric.

LLM-as-judge

A model scores outputs. Calibrate against human review and monitor bias, variability, and evaluation cost.

SFT — Supervised Fine-Tuning

Training on desired task outputs. Separate from indexing fresh documents.

PEFT — Parameter-Efficient Fine-Tuning

Adaptation with fewer trained parameters than full fine-tuning. Not implemented by this subsystem.

LoRA — Low-Rank Adaptation

A PEFT technique using low-rank updates to frozen model weights.

RLHF — Reinforcement Learning from Human Feedback

Training behavior using human preferences, often through reward modeling and policy optimization.

DPO — Direct Preference Optimization

Preference training from chosen/rejected output pairs without the same explicit RL loop as traditional RLHF.

Quantization

Reduced numerical precision for weights or activations. Evaluate quality and hardware behavior rather than assuming a universal speedup.

Temperature

A generation sampling control. Low temperature does not guarantee factual correctness.

Top-p

Nucleus sampling: restrict candidate tokens by cumulative probability mass. A host-generation setting, not a retrieval score.

SSE — Server-Sent Events

A one-way HTTP event-stream option for a host UI. The handbook proposes streaming contracts without claiming a built-in chat endpoint.

ADK — Agent Development Kit

Google agent runtime used by this host. It is distinct from Ragnor retrieval and LangSmith tracing.

LangChain

A proposed model/tool/agent integration alternative. It is not the current backend orchestrator.

LangGraph

A proposed explicit stateful workflow layer with nodes, edges, and checkpoint options.

A2A — Agent2Agent

A protocol for independently hosted agent interaction. Not currently exposed by the inspected backend.

Agent Card

A remote-agent capability and security description; discovery metadata is not a permission token.

Artifact

A task output in remote-agent collaboration. Validate provenance, access, and content before use.

Delegation

Granting a peer a narrow action or data scope on behalf of an originating principal.

Confused deputy

A service misuses its own privileges for a caller who lacks authority.

Checkpointer

Workflow state storage for resume and inspection; not automatically atomic with business writes.

Interrupt

A workflow pause for external input. Resuming it still requires actor authorization.

Reducer

A rule for combining state updates. Merge semantics must handle replay, order, and identity.

Replay

Re-execution or reconstruction from stored state/events. Side effects need explicit idempotency.

Human in the loop

A real review process with actor, payload, authority, and outcome—not only generated approval text.

JWT — JSON Web Token

Signed claims used for authentication here; signing does not encrypt the payload.

HttpOnly

A cookie flag limiting script access to the cookie; it does not prevent all authenticated actions by malicious script.

SameSite

A cookie sending policy that complements, rather than replaces, full CSRF and authorization review.

CSRF — Cross-Site Request Forgery

Unwanted requests using ambient browser credentials. Review state-changing routes and trusted origins.

Argon2

A password-hashing family used through argon2-cffi; parameters, dummy verification, and rate limits still matter.

RLS — Row-Level Security

Database row policies; proposed here as defense in depth, not present in the inspected migrations.

BYPASSRLS

A PostgreSQL role attribute that can bypass row policies; privileged roles need special review.

MVCC — Multiversion Concurrency Control

Database versioning used for concurrent visibility. A transaction alone does not serialize every business workflow.

Read Committed

A PostgreSQL isolation level with statement snapshots; successive statements may observe intervening commits.

Optimistic concurrency

A conditional update based on expected prior version/state, with explicit conflict handling.

Pessimistic locking

Holding a lock to protect a contested operation through a critical transaction.

Lost update

One concurrent write overwrites another, often when stale full-state blobs replace current state.

Flush

Sends pending ORM changes within the current transaction; not equivalent to commit.

Savepoint

A transactional rollback boundary inside a larger transaction; merely catching SQL errors does not create one.

Deadlock

Transactions wait cyclically on each other. Consistent lock order and bounded retry help.

Pool checkout timeout

A bound on waiting for a database connection, distinct from query or lock timeout.

NullPool

A SQLAlchemy pool mode opening fresh connections; used here only under test configuration to avoid cross-loop reuse.

JSONB

PostgreSQL binary JSON storage; flexible payloads still require validation, versioning, and privacy policy.

Decimal

Decimal-number arithmetic useful for exact monetary contracts; preserve it through transport and storage.

Expand and contract

A compatible multi-release schema migration strategy with backfill before destructive cleanup.

PITR — Point-in-Time Recovery

Restoring database state to a chosen point; derived indexes and jobs may then need reconciliation.

RPO — Recovery Point Objective

A declared acceptable data-loss objective, to be demonstrated by recovery design and drills.

RTO — Recovery Time Objective

A declared acceptable restoration-time objective, verified through measured drills.

Agent trajectory

Observed model/tool steps. Evaluate permissions, arguments, and effects in addition to names and order.

Task success

The intended authorized outcome actually occurred; not just a fluent final message.

answer_source

Host evaluation metadata distinguishing actual generated answers from context or offline-proxy substitutes.

Context proxy

Retrieved material scored as a substitute for an answer; useful diagnosis and not live-agent quality.

Ragas

A proposed evaluator for relationships among questions, contexts, responses, and references.

DeepEval

A proposed developer-oriented evaluation framework; selected metrics may call external judges.

TruLens

A proposed feedback/evaluation system including RAG relationship diagnostics.

Phoenix

A proposed tracing and evaluation investigation alternative; privacy depends on actual export and access policy.

Promptfoo

A proposed configuration-driven prompt/provider evaluation and assertion runner.

LangSmith

Current tracing vendor in the host, with separate optional experiment/evaluation capabilities.

Trace parentage

Causal nesting between turn, tool, and model spans; cross-SDK context may need explicit stitching.

Span

A timed operation within a trace. A span ID is a correlation identifier, not authentication.

Cardinality

The number of distinct metric-label values; raw claim/user IDs can make metrics costly and disclose data.

Calibration

Relationship between predicted confidence and observed correctness under a defined task and distribution.

Selective answering

Choosing when to answer or abstain; evaluate error among answered cases and overall coverage.

Hard negative

A deceptively relevant example that fails a material condition; controlling exclusions may still be relevant evidence.

Distillation

Training a smaller system from teacher signals; teacher errors and benchmark leakage still require review.

Data lineage

Identity of data, transformations, versions, and execution needed to reproduce a result.

Adjudication

An authoritative claim decision process, distinct from general support explanations of retrieved clauses.

Temporal applicability

Selecting evidence by the relevant time and verified contract; latest text is not always applicable text.
