IMPLEMENTED / OPTIONAL / PROPOSED

Choose by responsibility.

The backend uses ADK, LiteLLM, Ragnor, and LangSmith. The other systems below are alternatives or extensions. No optional framework was installed into the insurance project for this handbook.

A minimal useful stack

Keep deterministic pytest contracts for authorization and writes. Use Ragnor evaluation for retrieval diagnosis. Add a small agent-trajectory suite and one coherent tracing/experiment workflow. Introduce another evaluator only for a specific unanswered measurement question.

Read agent evaluation, library explanations, and observability together. A metric name does not make two libraries' inputs, judges, or scales equivalent.
